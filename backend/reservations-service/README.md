# Reservations Service

Servicio independiente basado en la API de reservas del repositorio de GitHub.

## Endpoints

- GET /api/hotels
- GET /api/hotels/:id
- POST /api/hotels
- PUT /api/hotels/:id
- DELETE /api/hotels/:id
- GET /api/guests
- POST /api/guests
- GET /api/reservations
- GET /api/reservations/:id
- POST /api/reservations
- PUT /api/reservations/:id
- DELETE /api/reservations/:id
- GET /api/stats
